# commits Conventions

## Format

```
<type>(<scope>): <description>
```

> `scope` is optionnal.

## Types

| Type       | Description                      |
| ---------- | -------------------------------- |
| `feat`     | new functionality                |
| `fix`      | Bug correction                   |
| `chore`    | Technical task (deps, config...) |
| `docs`     | Documentation                    |
| `style`    | Format                           |
| `refactor` | Refacto no fix, no feat          |
| `test`     | Add or modify tests              |
| `perf`     | Performance upgrade              |
